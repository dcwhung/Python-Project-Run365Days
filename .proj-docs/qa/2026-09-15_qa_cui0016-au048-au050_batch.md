### 6.2 根因：batch predicate 係 O(N²)

`src/api/service._sample_filter()` 砌出

```

    and_(activity_id == X2, position.in_([...])), ...,
    activity_id.in_(whole))
```

即 **N 條 OR arm**，而 SQLite 要對 numbered subquery 嘅**每一 row** 評估呢 N 條 arm。

`EXPLAIN QUERY PLAN`（64 tracks、`points=1`、SQL 5,827 字元）：

```
CO-ROUTINE anon_1
  CO-ROUTINE (subquery-3)
    SEARCH track_points USING INDEX sqlite_autoindex_track_points_1 (activity_id=?)
  SCAN (subquery-3)          ← 全掃 numbered rows
SCAN anon_1                  ← 再對每 row 評估 N 條 OR arm
USE TEMP B-TREE FOR ORDER BY
```

| 365 | 134,041 | 433.8 | **3,842.3** | **8.9×** | 28.67 |
