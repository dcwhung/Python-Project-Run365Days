## 問題描述

Vercel **唔係**由 GitHub Actions 部署嘅。`pages.yml` 綠代表 GitHub Pages 嗰邊 build 到，
同 Vercel 嗰個 serverless function 起唔起得到**完全冇關係**。今日 repo 入面冇任何嘢
喺部署之後 check 過 API。

呢個唔係假設出嚟嘅風險，`docs/deployment.md` §「What the first deployment taught」
一張表逐行記住六次失敗，每次都係**人手喺 Vercel Logs tab 度捉返出嚟**，其中兩種正正係
smoke test 應該接住嗰兩種：

| 失敗 | 今日點樣發現 |
|---|---|
| `ModuleNotFoundError: No module named 'flask'`（function 起唔到） | 人手睇 runtime log |
| export 寫咗個 **64 KB、0 個 activity** 嘅 database | 人手發現 |

## ⚠️ 設計上一定要解決嘅兩個陷阱

### (1) `/api/health` 回 200 唔代表冇事 —— 但**唔係**主票講嗰個理由

`api/graphql.py:24` 起唔到 app 嗰陣會起一個 minimal fallback app，**照樣答 `/api/health`**。
所以直覺會諗「淨係 ping health 分唔到真 app 定 fallback」。

**實測之下呢個講法唔準**：fallback 答嘅係 **HTTP 500** ＋ `{"status": "error", ...}`，
真 app 答 **200** ＋ `{"status": "ok", "db": ...}`。⇒ 單靠 status code 已經分得開，
一句 `curl --fail` 都捉到。

**真正 health 捉唔到嗰樣係另一件事**：DB **存在但空**。
`create_app` 只係 `make_engine`（檢查檔案在唔在），`health()` 回嗰個 `db` 係**路徑**唔係**行數**。
一個 0 activity 嘅 export 一樣 200 OK ——即係上面表入面嗰個 64 KB 事故。
實測：populated DB 同 empty DB **兩個都係 65536 bytes**，size 一樣分唔開。

⇒ **所以要夾一條真 GraphQL query**，而且要 assert 返嚟嘅**行數**，唔係 assert 200。

### (2) `deployment_status` trigger 喺呢個 repo 會靜英英完全唔行

Vercel **真係**出 GitHub Deployment（唔止 commit status）。實測 2026-09-17：
`GET /deployments` 100 條入面，`vercel[bot]` 開嘅有 `Production` 8 條、`Preview` 84 條，
淨低 8 條係 `github-pages`。`environment_url` 只有 Deployment 有，commit status 冇。

但 GitHub 規則：**`deployment_status` 只會用 default branch 上面嗰份 workflow file**。
本 repo default branch 係 `master`，而部署源頭係 `develop` ⇒ 一個寫成 `deployment_status`
嘅 workflow merge 落 `develop` 之後**一次都唔會行**，要等下次 release merge 上 `master`。
一個「由頭到尾唔行」嘅 gate 比一個「永遠綠」嘅 gate 更難發現。

⚠️ 同一條規則亦令 `schedule:` 唔用得（CUI-0052 個 audit workflow 已經明文記低咗同一個坑）。

⇒ 用 `push: develop`（冇呢個限制），自己 poll Deployments API 等 Vercel 報 success。

## 驗證方式

- 用一個本地起嘅真 app（populated DB）→ 必須綠
- 用 `api/graphql.py` 個 fallback app（指去一個唔存在嘅 DB）→ 必須紅
- 用一個 **meta 有、activities 空**嘅 DB → 必須紅（呢個 case 單獨驗到 row-count assertion 有力）
- 指去一個冇嘢聽 / 錯 base URL → 必須紅
- parsed YAML 核實：新 workflow **冇任何 job needs 佢**，而 `build.if` / `deploy.if` 冇郁
