**問題描述**

`RefusalAwareSchema.process_errors` 把 errors 分成兩堆，只把 `faults` 交返 `super()`：

```python
if faults:
    super().process_errors(faults, execution_context)
```

現有三條 logging 測試分別覆蓋「全部係 refusal」（`test_a_budget_refusal_is_not_logged_as_a_server_fault`）同「全部係 fault」（`test_an_unexpected_resolver_error_is_still_logged_as_a_server_fault`、`test_an_unseeded_budget_still_logs_its_traceback`）。兩種情況下 `faults` 同 `errors` 表現一樣（前者 `faults` 空、`if faults` 唔行；後者 `faults == errors`）。**只有混合 operation 先分得出。**

`RefusalAwareSchema` 自己個 docstring 就寫「classifying one kind and quietly taking the rest with it is a one-line mistake that no budget test would notice」——但守住嗰個 mistake 嘅參數自己冇被守。

**實測（2026-09-16，in-process mutation，清 `__pycache__`）**

把 `super().process_errors(faults, …)` 改成 `super().process_errors(errors, …)`：

```
oracle: 同一 operation 由 1 INFO + 1 ERROR  ->  1 INFO + 2 ERROR
        （多出嗰個 ERROR 就係 budget refusal 本身，連 exc_info）
pytest tests -q          -> 418 passed      ← 冇一條掛
pytest tests/test_api.py -> 159 passed      ← 冇一條掛
```

**建議補測（QA 已行通，可直接抄）**

```python
def test_a_refusal_and_a_fault_in_one_operation_are_logged_apart(
    year_client, caplog, monkeypatch
):
    # faults vs errors: 呢個係唯一分得出兩者嘅 shape。全 refusal 嘅 operation
    # 唔會行到 super()，全 fault 嘅 operation 兩個 list 一樣，所以兩邊都殺唔到
    # 「把未過濾 list 交返 super()」呢個 mutant。
    real = service.activity

    def selective(session, activity_id):
        if activity_id == "BOOM":
            raise _ResolverFaultError("the database went away")
        return real(session, activity_id)

    monkeypatch.setattr(service, "activity", selective)
    document = (
        '{ a1: activity(id: "…") { '
        + " ".join(f"t{i}: track(points: 1000) {{ sec }}" for i in range(11))
        + ' } a2: activity(id: "BOOM") { id } }'
    )
    with caplog.at_level(logging.DEBUG, logger="strawberry.execution"):
        errors = gql_errors(year_client, document)

    assert len(errors) == 2, "the client must still be told both things"
    records = _strawberry_records(caplog)
    refusals = [r for r in records if r.levelno == REFUSAL_LOG_LEVEL]
    faults = [r for r in records if r.levelno == logging.ERROR]
    assert len(refusals) == 1 and refusals[0].exc_info is None
    assert len(faults) == 1 and issubclass(faults[0].exc_info[0], _ResolverFaultError)
    # 最關鍵嗰句：refusal 冇跟住 fault 一齊上 ERROR
    assert not any("budget exhausted" in str(r.msg) for r in faults)
```

QA 已用真 Flask app 行過呢個 shape（未 mutate）：client 見 2 個 error、log 見 1 INFO（refusal，無 exc_info）+ 1 ERROR（fault，exc_info 帶住 marker），即正確行為。
