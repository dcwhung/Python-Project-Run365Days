## 問題描述

CUI-0054 嘅 gate 第一次喺 `master` 行 scheduled run，就報咗兩條**新公佈**、未入 allowlist 嘅 advisory
（`braces` 照 allowlist 只出 warning）：

| Package | Advisory | 受影響 | 喺樹入面 |
|---|---|---|---|
| `source-map-js` | GHSA-68fv-2mgg-jv7q（event-loop DoS，indexed source-map section offset） | `>=1.0.0 <1.2.2` | 1.2.1；1.2.2 已出 |
| `@graphql-tools/utils` | GHSA-7mx3-vvmw-hjmv（`mergeDeep` prototype pollution） | `<=12.0.0` | 11.2.2（另有 12.0.1 / 12.0.3 副本） |

`@graphql-tools/utils` 嘅難處：**11.x 冇任何 release 帶 fix**，而所有 `@graphql-codegen/*`
（連 registry 上最新版）都聲明 `^11.2.0`。`npm audit fix --force` 開出嘅「修正」同 CUI-0054 一樣，
係將 `@graphql-codegen/cli` 降級。

## 決定（用戶揀）

| 方案 | 結果 |
|---|---|
| **A. npm `overrides` 強制 `^12.0.3`（揀咗）** | 真修，唔係 suppression；代價係違反 codegen 聲明嘅 `^11` 範圍 |
| B. 有期限 allowlist（同 `braces`） | 唔郁依賴，但係 suppression；路徑多，entry 要逐條寫 |

## 修正

| Commit | 內容 |
|---|---|
| `c1eeb02` | `npm update source-map-js`：lockfile 只改呢一個 entry（1.2.1 → 1.2.2），`package.json` 冇郁 |
| `b0c4751` | `frontend/package.json` 加 `"overrides": {"@graphql-tools/utils": "^12.0.3"}`；lockfile 除咗 utils 收窄做單一 12.0.3，冇其他 package 版本改變；新增 `tests/test_npm_overrides.py` |

用 `npm update` 而唔用 `npm audit fix`：後者會順手將一批 `@graphql-codegen/*` 升 minor / patch，
同修 advisory 無關，所以唔要。

## Override 幾時拎走

`tests/test_npm_overrides.py` 規定 override **存在 ⇔ 仲有 dependent 聲明 11.x range**：

- codegen 升上 12 嗰日，測試會紅，提醒拎走 override（唔會留低一個冇人知點解喺度嘅 override）
- 有人移走 override 但 codegen 仲係 `^11`，測試都會紅
- `package.json` 加任何新 override 而冇對應測試，第二條測試會紅

兩個方向都用 in-process mutant 驗過（`_declared_ranges` 改做淨係 `^12` → 紅；多一個未知 override → 紅）。
Red 階段（未加 override）係 assertion fail，唔係 collection error。
