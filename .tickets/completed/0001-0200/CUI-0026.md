## 問題描述

`.proj-docs/tickets.md` 嘅 W-024 更正段落（`4d0914f` 已 merge）寫住：

```
limit=150: 365/365 入到 sampler -> divergent = 0   <- 假綠！149 係質數嘅算術巧合
```

「**149 係質數**」呢個解釋**唔啱**。真正嘅判準係 **step 分母 `limit - 1` 嘅奇偶**，
同質數無關。如果依照「質數」呢個錯誤 mental model 去揀將來嘅 `TRACK_POINTS`，
會揀到錯嘅值（見下面 `limit = 64`：63 = 3²×7 唔係質數，但一樣完全冇 tie）。

## 正確嘅 characterisation

`downsample(items, limit)` 取 `step = (n-1)/(limit-1)`，第 `i` 個 index 係 `round(i * step)`。
出現 half-way tie 即係要 `i*(n-1)/(limit-1)` 嘅小數部分**啱啱好等於 0.5**。

設 `d = limit - 1`：

```
i*(n-1)/d = k + 1/2   ⟺   2*i*(n-1) = d*(2k+1)
```

- **`d` 係奇數**：左邊一定係偶數，右邊 `奇 × 奇 = 奇`。偶 ≠ 奇 → **永遠無解，一個 tie 都冇**。
- **`d` 係偶數**：有解，tie 大量出現。

即係話 —— **`limit` 係偶數 ⇒ `d` 奇數 ⇒ 完全免疫；`limit` 係奇數 ⇒ `d` 偶數 ⇒ 會 tie。**

`limit = 64` 係反例：`63` 唔係質數，但一個 tie 都冇 —— 質數論在此失效，奇偶論全中。

同真實 export（123 個相異長度）嘅分歧率亦完全跟奇偶走：

```
偶數 limit：  2 -> 0%     150 -> 0%     400 -> 0%     600 -> 0%（另有 n<=limit 早返）
奇數 limit：  3 -> 27.6%    5 -> 51.2%    7 -> 39.0%   97 -> 83.7%  193 -> 84.6%  241 -> 82.1%
```
