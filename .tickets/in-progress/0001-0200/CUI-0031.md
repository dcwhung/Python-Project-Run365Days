## 問題描述

CUI-0024 第 5、6 項將「寫死數字 + 覆蓋範圍描述」改成「只留覆蓋範圍描述」，
理由係「覆蓋範圍描述本身係準確而且唔會 drift」。方向係啱嘅，但改寫**換走咗句子嘅主語**：

| | 之前 | 之後 |
|---|---|---|
| README | 「**93 tests** cover the geo and time helpers…」 | 「**The Python suite** covers the geo and time helpers…」 |
| README | 「Front end: **87 Vitest tests** cover…」 | 「Front end: **the Vitest suite** covers…」 |

「93 條測試涵蓋 X」係講**其中 93 條**做乜 —— 一個關於子集嘅、準確嘅陳述。
「The Python suite covers X」係講**成套**做乜。後面嗰個 list 一隻字冇改，
所以一個本來準確嘅局部清單，變成一個唔完整嘅整體描述。
